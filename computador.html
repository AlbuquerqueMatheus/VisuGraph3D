Guia de projetos

Seu computador

O que você faz no código vivo também roda no seu computador, com as ferramentas de quem faz sites com three.js: o Node.js, um terminal, um editor de código e o Vite. Aqui está como instalar cada um, como rodar um projeto baixado do VisuGraph e o que fazer quando algo dá errado.

O que você vai usar

Node.js
Roda JavaScript fora do navegador. Vem com o npm, que baixa bibliotecas como o three.js.
Um terminal
A janela onde se digitam os comandos, como npm install. Todo sistema já tem um.
VS Code
O editor de código, com um terminal dentro. Qualquer editor serve, mas este ajuda bastante.
Vite
O servidor que mostra a página enquanto você programa e prepara o site para publicar. Não precisa instalar: cada projeto traz o seu, pelo npm.

Node.js

Baixe a versão LTS em nodejs.org. LTS quer dizer suporte de longo prazo: é a versão estável, a que recebe correções por mais tempo. Os projetos do VisuGraph pedem a 22.12 ou mais nova.

Windows

Baixe o instalador (o arquivo .msi) e avance com as opções que já vêm marcadas: elas põem o node e o npm ao alcance do terminal.

macOS

Baixe o instalador (o arquivo .pkg) e siga as telas. Quem usa o Homebrew pode instalar com brew install node.

Linux

O pacote da distribuição costuma ter uma versão antiga. A página de download do nodejs.org mostra os comandos para instalar a LTS, por exemplo com o nvm, que instala o Node na sua pasta, sem precisar de administrador.

Depois de instalar, abra um terminal novo e confira:

node -v
npm -v

Cada comando responde com um número de versão, como v22.12.0. Se a resposta for que o comando não existe, veja os problemas comuns.

O terminal

No Windows, procure Terminal (ou PowerShell) no menu Iniciar. No macOS, procure Terminal no Spotlight (Cmd + Espaço). No Linux, Ctrl + Alt + T abre um na maioria das distribuições. No VS Code, o menu Terminal → Novo Terminal abre um dentro do editor.

O terminal está sempre dentro de uma pasta, e os comandos rodam nela. Quando abre, ele começa na sua pasta de usuário. Os comandos para andar entre as pastas:

cd galaxia
entra na pasta galaxia; cd .. volta uma pasta
ls
lista o que há na pasta (no Prompt de Comando do Windows, dir)
pwd
mostra em que pasta você está
Tab
completa o nome de uma pasta ou arquivo começado
↑
traz de volta o comando anterior
Ctrl + C
interrompe o que está rodando, como o servidor do Vite

O editor

O VS Code é gratuito e funciona nos três sistemas. Ele colore o código, completa os nomes do three.js enquanto você digita e tem um terminal embutido.

Para trabalhar num projeto, abra a pasta inteira (Arquivo → Abrir Pasta), e não um arquivo solto: assim o editor enxerga todos os arquivos, e o terminal dele já começa na pasta do projeto.

Rodar um projeto baixado

  1. No código vivo, use Baixar → Projeto Vite (.zip) na barra de ferramentas, ou o botão de baixar de um passo de projeto.
  2. Descompacte o arquivo. No Windows, clique nele com o botão direito e escolha Extrair Tudo: abrir o .zip com dois cliques só mostra o que tem dentro, e os comandos não funcionam lá.
  3. Abra a pasta que saiu do .zip no VS Code, e o terminal dele.
  4. Instale as bibliotecas que o projeto pede. Elas vão para a pasta node_modules; só é preciso rodar de novo quando o package.json mudar. 
    npm install
  5. Ligue o servidor. Ele mostra o endereço da página, http://localhost:5173: abra no navegador. Deixe o terminal aberto enquanto programa, porque cada arquivo salvo atualiza a página. Ctrl + C desliga. 
    npm run dev

Os arquivos do projeto

index.html
a página, com o <canvas> onde a cena aparece
src/cena.js
a cena, com o código escrito no VisuGraph
src/main.js
o que o visor do VisuGraph fazia: o renderer, o tamanho da janela, os controles do mouse e o laço que desenha cada quadro
package.json
o nome do projeto, os comandos e as bibliotecas, com as versões
vite.config.js
a configuração do Vite para publicar
node_modules
as bibliotecas baixadas pelo npm; não se edita, e o npm install refaz

Publicar

npm run build
npm run preview

O npm run build gera a pasta dist, com o site pronto, e o npm run preview mostra essa versão antes de publicar. Para pôr no ar, envie o conteúdo da pasta dist a uma hospedagem de sites estáticos, como o GitHub Pages ou o Netlify (no Netlify, dá até para arrastar a pasta para a página).

Começar do zero

Os projetos baixados do VisuGraph são projetos Vite comuns. Para criar um novo, sem baixar nada, o próprio Vite monta a estrutura: 

npm create vite@latest minha-cena -- --template vanilla
cd minha-cena
npm install
npm install three
npm run dev

Se ele perguntar se deve instalar e começar agora (Install and start now?), responda que não, para seguir os comandos acima. O modelo vanilla é JavaScript puro, sem frameworks, e vem com um exemplo de contador no src/main.js. É ali que entra a cena, como no main.js e no cena.js de um projeto baixado.

Problemas comuns

“node não é reconhecido como comando” ou “command not found: node”

O terminal não acha o Node. Feche e abra o terminal (e o VS Code) depois de instalar: um terminal aberto antes da instalação não fica sabendo dela. Se continuar, instale de novo, com as opções que vêm marcadas.

No PowerShell: “a execução de scripts foi desabilitada neste sistema”

O Windows bloqueia por padrão os scripts que o npm usa no PowerShell. Rode uma vez o comando abaixo, que libera os scripts criados no computador para o seu usuário, e abra o terminal de novo. Outra saída é usar o Prompt de Comando (cmd) em vez do PowerShell. 

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
“ENOENT” e “package.json” no erro do npm

O terminal não está na pasta do projeto. Rode ls e veja se o package.json aparece; se não, entre na pasta certa com cd. Se dentro da pasta houver outra com o mesmo nome, entre nela também.

A página fica em branco ao abrir o index.html com dois cliques

Aberta direto do disco (um endereço file://), a página não carrega módulos. Abra pelo endereço que o npm run dev mostra, http://localhost:5173.

“Port 5173 is in use”

Não é um erro: outro servidor, talvez de outro terminal, já usa a porta, e o Vite pega a seguinte. Use o endereço que ele mostrar, ou desligue o outro servidor com Ctrl + C.

A página abre, mas a cena não aparece

Abra o console do navegador (F12, aba Console): o erro diz o arquivo e a linha. Os mais comuns são um nome digitado errado (ReferenceError: … is not defined) e um import com o caminho errado. Erros de sintaxe, o Vite mostra por cima da própria página.

O npm install falha ou não termina

Ele precisa de internet para baixar as bibliotecas. Tente de novo; numa rede com proxy, como a de algumas empresas e universidades, o npm precisa ser configurado para ela.
